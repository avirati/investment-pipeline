## Product

- Hoplite is designed for developers who want to deploy coding agents that can work on software projects in a real, isolated development environment and automate tasks like editing code, running tests, and opening pull requests.[E2]
- Hoplite describes itself as a platform for effortless cloud coding agents that can run in isolated sandboxes and handle hundreds of concurrent agents to perform quality assurance and developer automation tasks.[E1][E3]

- Hoplite prepares video recordings of all new feature changes for easy verification without manual walkthroughs, storing these flows in a QA library to be replayed without rerunning agents.[E1][E3]

## Product

- Kontext CLI is a credential broker for AI coding agents written in Go.[E3]

- The Kontext CLI is open source and licensed under MIT, with a public repository on GitHub at kontext-security/kontext.[E2]
- Kontext CLI runs locally and injects credentials into the AI agent's runtime environment during sessions, using OAuth and short-lived tokens.[E3]
- The CLI streams every tool call made by the AI agent for audit as it runs, capturing what was accessed, who did it, and session context.[E3]
